# vrdrum

A VR drum kit built with Godot 4 and OpenXR. The main target is PSVR2 on PC through the PC adapter, which runs on SteamVR. Other OpenXR headsets should work too: Valve Index, Vive, Quest or Pico over Link, and Windows Mixed Reality.

See [docs/PLAN.md](docs/PLAN.md) for the technical design and milestones.

## Status

M0 to M3 are built: project setup, one snare, the full kit, and comfort and customization.

- **The kit:** kick, snare (head and rim), hi-hat, two rack toms, a floor tom, crash (bow and edge) and ride (bell, bow and edge).
- **Sound:** recorded samples from Karoryfer's CC0 [Big Rusty Drums](https://github.com/sfzinstruments/karoryfer.big-rusty-drums), with several velocity layers and round-robin takes. In VR, each drum is heard from where it stands.
- **Hit detection:** a swept stick-tip test, so fast strokes aren't missed. Strike speed picks the velocity layer.
- **Hi-hat:** the pedal sets closed, half-open or open. Closing it plays the foot "chick" and cuts off a ringing open hat.
- **Cymbals:** they wobble when hit. Touching a cymbal's edge with your hand (controller) chokes it.
- **Highlights:** the part you hit lights up: drum head or hoop, and the cymbal's bell, bow or edge ring.
- **Menu:** settings for hit sensitivity and dynamics, stick length and angle, and mixer volumes. Also left-handed mode (a mirrored kit with swapped pedals) and an inverted hi-hat pedal.
- **Kit editor:** move pieces by grabbing them with a stick (VR) or dragging them (desktop). There are default and compact presets and three save slots. Your layout is restored at startup.
- **Other:** a practice room, controller haptics, a debug overlay, and a desktop mode for testing without a headset.

Nothing has been tuned on a headset yet.

## Running

1. Install [Godot 4.7](https://godotengine.org/download) (standard build, not .NET).
2. Open `project.godot` in the editor and press Play.

With a headset:

- **PSVR2:** start SteamVR with the PSVR2 PC adapter connected, and make sure SteamVR is your active OpenXR runtime (SteamVR → Settings → OpenXR). The game starts in VR automatically.
- **Other headsets:** the same applies to any OpenXR runtime.

VR controls:

| Input | Action |
|---|---|
| Swing the sticks | Play |
| Right trigger | Kick (left trigger in left-handed mode) |
| Left trigger (hold) | Close the hi-hat (half-pressed = half-open) |
| Hand on a cymbal's edge | Choke the cymbal |
| A / X or the menu button | Open or close the menu, or leave the kit editor |
| Point a stick at the menu + trigger | Click |
| In the kit editor: touch a piece + hold trigger | Move it |
| B / Y (menu on Vive or WMR) | Move the kit to just below where your sticks are held |
| Thumbstick click | Toggle the debug overlay |

With no headset (or when launched with `-- --desktop`), you get a desktop view:

| Input | Action |
|---|---|
| Mouse | Aim at a drum or cymbal |
| Left click / `J` | Right stick |
| Right click / `F` | Left stick |
| Hold `Shift` | Soft stroke |
| `Space` | Kick |
| Hold `V` | Close the hi-hat |
| `F3` | Debug overlay |
| `Esc` | Open or close the menu, or leave the kit editor |
| In the kit editor: drag / scroll / `Shift`+scroll | Move / raise or lower / tilt a piece |

Keyboard and gamepad pedal bindings also work in VR. `Space`/`V` suit USB foot switches, and a gamepad's triggers work too.

## Tests

```sh
godot --headless --xr-mode off --audio-driver Dummy --import
godot --headless --xr-mode off --audio-driver Dummy --script res://tests/run_tests.gd
```

CI runs the same commands on every push.

## Settings and layouts

Settings are saved to `user://settings.cfg`, and layouts to `user://layouts/`. The editor's Project → Open User Data Folder menu shows where that is on your machine.

## Sounds

The drum samples in `assets/kits/rusty/` are generated by `tools/build_sample_kit.py` from the CC0 source; see that folder's README. If the kit is missing, the game falls back to synthesized sounds (`scripts/audio/drum_synth.gd`).

## Controller bindings

`openxr_action_map.tres` is generated by `tools/generate_action_map.gd`. It takes Godot's default action map and adds Index, Vive, WMR and simple-controller profiles. PSVR2 Sense controllers get bindings through SteamVR, which maps them onto one of these profiles. You can adjust them in SteamVR's controller binding UI.

To regenerate the file:

```sh
godot --headless --xr-mode off --script res://tools/generate_action_map.gd
```
